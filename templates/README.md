# Official Templates Directory

This directory centralizes all official project templates and reference materials for E-Tayo Locational Clearance & Zoning Permits.

## Folder Structure

* **`official/`**
  * `ANNEX_D_TEMPLATE.pdf`: The official, clean 2-page vector template for **ANNEX D - PROJECT EVALUATION REPORT**. This matches the production template served to the web app PDF generator at `frontend/public/templates/ANNEX_D_TEMPLATE.pdf`.
* **`reference/`**
  * `ANNEX_D_SAMPLE_FILLED.pdf`: Reference sample with sample fields and layout guidelines.
  * `extracted_x7.png`: Visual layout reference for Section D (Zoning Site Vicinity Sketch / Lot Boundaries).
