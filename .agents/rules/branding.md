# Branding Guidelines: eTAYO

1. **System Name**: Always use `"eTAYO"`.
2. **Prohibited Variations**: Never use `"e-Tayo"`, `"Etayo"`, or `"E-Tayo"` in user-facing texts, headings, metadata, or documentation.
3. **Consistency**: Ensure all newly generated UI text, emails, SMS, PDF footers, and AI responses adhere strictly to the "eTAYO" brand name.
